get data of licensee on excel file
    [Arguments]    ${filename}    ${licenseename}
    [Documentation]    This keywork is used to get data from exported excel file of Licensees Win Loss on LA \ based on file name (Product) and Licensee name:
    ...    - Data return: TotalTrans, Turnover, Customerwl, Amount
    ...    - Data exclude: BA, RACING (2 these product get different column Amount)
    Open Excel    C:\\Test Data\\${filename}
    ${rowcount}    Get Row Count    Data
    ${AmoutofLic}    Evaluate    ${rowcount}-11
    : FOR    ${index}    IN RANGE    0    ${AmoutofLic}
    \    ${i}    Evaluate    ${index}+5
    \    ${licenseenameLicWL}    Read Cell Data By Coordinates    Data    1    ${i}
    \    ${contain}    does value equal    ${licenseenameLicWL}    ${licenseename}
    \    ${row}    Set Variable If    '${contain}'=='True'    ${i}
    \    ${TotalTrans}    Run Keyword If    '${contain}'=='True'    Read Cell Data By Coordinates    Data    2
    \    ...    ${i}    #Total Trans
    \    ${Turnover}    Run Keyword If    '${contain}'=='True'    Read Cell Data By Coordinates    Data    3
    \    ...    ${i}    #Turnover
    \    ${Customerwl}    Run Keyword If    '${contain}'=='True'    Read Cell Data By Coordinates    Data    4
    \    ...    ${i}    #Customerwl
    \    ${Amount}    Run Keyword If    '${contain}'=='True'    Read Cell Data By Coordinates    Data    10
    \    ...    ${i}    #Amount
    \    Exit For Loop If    '${contain}'=='True'
    [Return]    ${TotalTrans}    ${Turnover}    ${Customerwl}    ${Amount}

compare winloss by product for sportsbook
    [Arguments]    ${filename}
    [Documentation]    This keywork is used to compare data between Win loss by Product and \ exported excel file for Sportsbook
    ...
    ...    - Open exported excel file of Licensee WL for Sportsbook
    ...
    ...    - Start loop with row of 1st licensee
    ...
    ...    - Get data from Amount column of file
    ...
    ...    - Get data from Win Loss by Product report on site for Sportsbook
    ...
    ...    - Compare then return status
    ...
    ...    - Continue loops with next licensees
    ...
    ...    - ** Note: Make an exception case for AG licensee caused by it is belong to wildcard text with AG Casino Product
    Open Excel    C:\\Test Data\\${filename}
    ${rowcount}    Get Row Count    Data
    ${AmoutofLic}    Evaluate    ${rowcount}-11
    #SportsBook
    : FOR    ${index}    IN RANGE    0    ${AmoutofLic}
    \    ${i}    Evaluate    ${index}+5
    \    ${licenseenameLicWL}    Read Cell Data By Coordinates    Data    1    ${i}
    \    ${amountLicWL}    Read Cell Data By Coordinates    Data    10    ${i}
    \    ${amountLicWLWLbP}    Run Keyword If    '${licenseenameLicWL}'<>'AG'    Get Text    xpath=.//td[contains(text(),'${licenseenameLicWL}')]/following::td[1]    #Sportbook
    \    ...    # Exclude case: AG licensee is the same name with AG Casino column
    \    ${amountLicWLWLbP}    Run Keyword If    '${licenseenameLicWL}'<>'AG'    remove string    ${amountLicWLWLbP}    ,
    \    Run Keyword If    '${licenseenameLicWL}'<>'AG'    check value equal with approximation    ${amountLicWL}    ${amountLicWLWLbP}
    \    ${amountLicWLWLbPforAG}    Run Keyword If    '${licenseenameLicWL}'=='AG'    Get Text    xpath=(.//td[contains(text(),'${licenseenameLicWL}')]/following::td[1])[2]    #Sportbook for AG licensee
    \    ...    # Exclude case: AG licensee is the same name with AG Casino column
    \    ${amountLicWLWLbPforAG}    Run Keyword If    '${licenseenameLicWL}'=='AG'    remove string    ${amountLicWLWLbPforAG}    ,
    \    Run Keyword If    '${licenseenameLicWL}'=='AG'    check value equal with approximation    ${amountLicWL}    ${amountLicWLWLbPforAG}
