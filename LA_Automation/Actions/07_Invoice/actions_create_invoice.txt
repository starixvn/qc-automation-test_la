    ...    ELSE IF    '${is_waive}'=='True' and '${product}'=='BA' and '${rate}' <> 'None'    Evaluate    ${settlement_licensee_gross_win_in_waive} - ${settlement_ba_comm_in_waive}

get date after waive

    [Documentation]    This action will return date after date range in month.
    ...
    ...    Note: Waive is applied to new licensees, waive start from launched date of licensee.

    ...    EX:
    ...    Case 1: Waive is applied from 1-20 Jun, this action will return date range 21-30 Jun

    ...    Case 2: Waive is applied from 20-30 Jun, this action will return date range is None. because 1-19, licensee hasn't launched yet

    [Return]    ${from_date}    ${to_date}
